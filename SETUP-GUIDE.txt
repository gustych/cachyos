──────────────────

BEFORE SYSTEM UPDATES:

  $ sudo pacman -Syu
  $ safety-manager post "system update"

  $ safety-manager status

  Shows status of snapshots, backups, and firewall.

CREATE REGULAR BACKUPS:
  $ safety-manager full-backup

  Creates snapshot + dotfiles backup + package list backup.

EDIT CRITICAL FILES SAFELY:
  $ safe-edit /etc/ssh/sshd_config

  Automatically backs up before editing and validates after.

LIST SNAPSHOTS:
  $ safety-manager list-snapshots

  Shows all Btrfs snapshots with timestamps.

RESTORE FROM SNAPSHOT (Emergency):
  $ snapshot-manager restore <number>
  $ reboot

  ⚠ Only use if system is broken!

BACKUP YOUR DOTFILES:
  $ safety-manager backup-dotfiles

  Saves current configuration to git repository.

TROUBLESHOOTING:
────────────────

Hyprland config errors:
  $ cat ~/.config/hypr/hyprland.conf | grep -n "error"

  If errors persist, restore from backup:
  $ dotfiles-backup restore

Firewall blocking something:
  Check logs:
    $ sudo journalctl -u ufw -f

  Temporarily disable (for testing):
    $ sudo ufw disable

  Re-enable:
    $ sudo ufw enable

System won't boot after update:
  1. Boot from live USB
  2. Mount your root partition
  3. Restore from snapshot using Snapper

Safety manager not in PATH:
  $ source ~/.bashrc

  Or manually add:
  $ export PATH="$HOME/.local/bin/system-safety:$PATH"

Touchpad not working:
  Check if driver is loaded:
    $ cat /proc/bus/input/devices | grep -i touchpad

  Install libinput:
    $ sudo pacman -S libinput xf86-input-libinput
